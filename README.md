## ✨ Особенности

* **Полный офлайн и независимость**: данные хранятся исключительно на вашем компьютере в выбранном вами `.sqlite` файле. Никаких сторонних серверов, облачных аккаунтов или подписок.
* **Логины и банковские карты**: удобное раздельное хранение учетных записей веб-сервисов и платежных реквизитов (номер карты, срок действия, CVV, держатель, PIN).
* **Мгновенный поиск FTS5**: встроенный полнотекстовый движок поиска SQLite FTS5 с быстрым поиском по названию, логину, заметкам и тегам.
* **История паролей**: сохранение до 5 предыдущих версий паролей и PIN-кодов с возможностью мгновенного восстановления в один клик.
* **Встроенный генератор паролей**: гибкая настройка длины, регистра, цифр и спецсимволов с оценкой надежности.
* **Аудит безопасности**: автоматическое обнаружение дублирующихся, скомпрометированных или слишком простых паролей.
* **Современный интерфейс**: удобный рабочий режим с широким двухколоночным экраном, Тёмная и Светлая темы, русский и английский языки (`Ctrl+F` для поиска, `Ctrl+N` для создания записи).
* **PIN и автоблокировка**: быстрая разблокировка по PIN-коду и настраиваемый таймер автоматической блокировки при бездействии.

## 🔒 Безопасность

* **Шифрование базы SQLCipher**: вся локальная база данных зашифрована на диске по стандарту SQLCipher (AES-256).
* **Усиленный KDF**: мастер-ключ формируется с помощью алгоритма PBKDF2-SHA-256 (600 000 итераций по рекомендациям OWASP).
* **Шифрование секретов**: чувствительные поля дополнительно защищаются алгоритмом AES-256-GCM.
* **Безопасность буфера обмена**: скопированные пароли автоматически очищаются из буфера обмена Windows через 30 секунд.
* **Изоляция окружения (Electron Sandbox)**: Renderer-процесс изолирован (`nodeIntegration: false`, `contextIsolation: true`, песочница Electron включена).

## 🛡️ Проверка целостности (SHA-256)

Перед первым запуском рекомендуется сверить контрольную сумму скачанного файла:

```powershell
Get-FileHash -Path "$HOME\Downloads\KeyCurator-1.9.1-x64-Setup.exe" -Algorithm SHA256
```

Эталонные контрольные суммы для версии **v1.9.1**:

```text
d4eefd330a6ad84cea5b2a388fcb0735bfbc8f45d5012cfaac72cfe890c1354c  KeyCurator-1.9.1-x64-Setup.exe
3db04f05e93047adec0e685b061f633017243630d81eb3d70f17ea26e5768358  KeyCurator-1.9.1-x64-Portable.exe
```

> **Примечание**: Сборки пока не подписаны платным коммерческим сертификатом. Windows SmartScreen при первом запуске может показать стандартное предупреждение. Нажмите *«Подробнее»* → *«Выполнить в любом случае»*, предварительно сверив SHA-256.

## 🔄 Инструкция по обновлению

1. Скачайте новую версию файла установщика или portable-версию со страницы релизов.
2. Закройте работающий KeyCurator.
3. Запустите новый установщик или замените portable-файл.
4. **Файл вашего сейфа (`.sqlite`) сохраняется на прежнем месте** — повторно введите мастер-пароль и продолжайте работу.
